サブスクは売れる。売る価値があったかは、変動費が決める。

AIアプリのトライアル転換率は非AIより 52% 高く、年間プランの解約は約 30% 速い。 リクエストごとに動く原価に対して、使い放題の価格設計は構造的に破綻します。 サブスクとクレジットのハイブリッドを実際に運用できているアプリは、10本に1本ほど。

請求ではなく、認可

各アクションの直前に1回。承認するか、断るか、「安いモデルを提示する」か。 拒否はエラーではありません。理由と解決策を返すので、 ユーザーが壁に当たった瞬間が、そのままトップアップの瞬間になります。

押さえて、約定する

実行前に額面を確保し、実際に使われた分で確定します。差額は自動で戻ります。

拒否はデータになる

残高逼迫、残高ゼロ、粗利のマイナス転落。それぞれがホールドアウト群つきのイベントになるので、 施策が「実行されたか」ではなく「効いたか」が分かります。

安いか、出さないか

代替案は、本当に安くて本当に払える場合にだけ提示します。 こちらがリクエストを勝手に振り替えることはありません。

いま書いている呼び出しの、前後3行

const guard = tegata.guard({ subjectId, action: 'chat.completion' });
const d = await guard.issue({ model, inputTokens, maxOutputTokens });
if (d.dishonored) return renderPaywall(d.remedy);

try { const res = await anthropic.messages.create({ ... });
      await guard.capture(res.usage); }
catch (e) { await guard.release(); throw e; }

プロンプトが当社を通ることはありません。SDK が送るのはトークン数であって、内容ではありません。 当社に到達できないときもアプリは動き続けます。 縮退時の挙動は、障害の最中に気づく仕様ではなく、事前に選ぶ設定です。

台帳を持ち出して、自分で検証する

すべての保留・約定・不渡りが、追記専用のひとつの台帳に載ります。 ハッシュチェーンはエントリ自体に対して定義されているので、 エクスポートを持つ人は、それを作ったサービスを信頼せずに計算を検証できます。

$ curl /v1/register/export | tegata-verify
  user_8f21   balance 991   reserved 0   available 991
  chain verifies — 5 entries across 2 subjects, manifest agrees

$ # 1バイト書き換える
  FAIL  user_8f21 seq 2: hash does not match the entry contents
  chain FAILED — 1 issue(s)

金を扱うコードは、読めるべきです。台帳・ポリシーエンジン・監査フォーマットは オープンソース。 対価をいただくのは、止まらないことに対してです。
