## 0. 方法論（先に読む）

### 0.1 母集団は解決済みの問題だった

**TrustMRR**（`trustmrr.com`）が決定的。決済プロバイダ（Stripe / RevenueCat / LemonSqueezy /
Polar / Superwall）の API で検証された収益を公開しており、**自己申告ではない**。
AI カテゴリだけで約 3,569 社。MCP サーバ（`trustmrr.com/mcp`）も公開されている。

**したがってリスト構築は手作業ではなくクエリで行う。** 推奨手順:

1. TrustMRR の AI / Content Creation / Entertainment カテゴリを MCP 経由で取得
2. `$5k ≤ MRR ≤ $100k` かつ `NOT for_sale` でフィルタ
3. 創業者ハンドルだけ人手でエンリッチ（ここが唯一のボトルネック）

歩留まりの実測: AI カテゴリ約30社を精査して、consumer/prosumer AI アプリは8〜10社、
うち収益帯が合うのは約半分、さらにその**約40%が売却中**。
**通過率はおよそ 1/8〜1/10**。3,569社に対して有資格プールは理論上 350〜450社で、
必要な10〜15社に対して十分過ぎる。

### 0.2 発見した精度上のリスク（重要）

**検索エンジンの要約は、無関係な企業間で数字を取り違える。**
実例: `$19.3K verified MRR (1,012 active subscriptions)` という同一文字列が、
ある検索では A 社、別の検索では B 社に帰属して返された。一次ページを直接取得すると
どちらとも異なる数字だった。別の例では、all-time 収益が 30日収益として報告されていた。

**規則: 数字は必ず一次ページの直接取得で確認する。検索結果の要約を引かない。**
`icp-interviews.md` §1-4「数字を必ず1つ持ち帰る」の前段として、
**こちらが持っていく数字も同じ基準で検証されていなければならない。**

### 0.3 経路別の生産性

| 順 | ソース | 評価 |
|---|---|---|
| 1 | **TrustMRR** | 圧倒的。検証済み収益・創業者名・サブスク数・チーム規模・売却中フラグが構造化されている |
| 2 | **Indie Hackers のインタビュー記事** | 質は最高（創業者ハンドル + 収益 + 日付 + 価格モデルが1ページに揃う）だが量が少ない |
| 3 | 汎用 Web 検索 | **低品質かつ有害**。SEO まとめ記事ばかりで、帯外の有名企業を再循環させ、§0.2 の取り違えを起こす。一次ソースの特定にのみ使う |
| 4 | Product Hunt / Acquire.com / Reddit | 今回は不作。売却中在庫は TrustMRR 側がより良いデータで持っている |

### 2.0 結論（都合の良い方ではない）

**市場は二つに割れていて、現時点で実在するのは片方だけ。**

| セグメント | 内容 | 判定 |
|---|---|---|
| **(b) エージェントが予算を焼く**（LLM / コーディングエージェントのトークン支出） | **READY。痛みは実在し、日付と数字が取れる。だが金は「推論費」であって「外部購買」ではなく、しかも既に混雑している** |
| **(a) エージェントが外部ベンダーに払う**（TEGATA の本来のテーゼ） | **EARLY。** 本番でエージェントが実際に外部予算を動かしていると確認できた非 crypto 企業は**2社**のみ |

**「エージェントが物を買う」系の成果物のほとんどは、買い手ではなく統制レイヤーを売る側だった。**
需要の前に供給が積み上がっている。

**この非対称性自体が最大の発見**: §2.3 の「怖いから止めている」証拠は**容易に集まった**。
一方「もうやっていて痛い」証拠は**極めて集まりにくかった**。
恐怖は実在する。未来も実在する。**予算はまだ実在しない。**

### 2.4 反証 — 作る前に読むこと

**1. 購買レールの取扱高は相当部分が実体を伴わない。** `第三者報道`
x402 は日次約131,000トランザクション、**総額は約$28,000**（平均$0.20）。
Artemis のアナリストは**観測されたトランザクションの約半分が自己取引またはウォッシュトレード**と
評価し、2月の活動を「いまだ大部分が蜃気楼」、380万件のスパイクを「需要ではなくインフラのテスト」と
断定。**記事はエージェント決済を受け入れている事業者を1社も挙げていない。**
主要インフラ企業は軒並み x402 対応を出荷済み＝**需要の裏付けのない供給側の積み上げ**。

**2. コンシューマのエージェント決済は既に一度失敗している。** `第三者報道`
Shopify の数百万加盟店のうち Instant Checkout を稼働させたのは**30社未満**。
Walmart はチャット内決済の転換率が自社サイト誘導の**約1/3**と計測。
OpenAI は2025年9月に投入し「2026年初頭には撤退」、「AI で発見し、自社サイトで買う」に転換。

**3. 中央値の企業は AI にほとんど金を使っていない。** `第三者報道`
Ramp AI Index（2026年6月）: ソフトウェア企業の**上位1%はエンジニア1人あたり年$89k**、
**中央値は$137** — **680倍の差**。ICP はその上位1%であり、実際に薄い。

**4. 最も信頼できる実務者の報告は「恐れている失敗モードは実際の失敗モードではない」と言っている。**
匿名 HN（2026-03-15）: 「**人が心配する失敗モード**: エージェントが暴走して$10k 使う。
**実際に起きる失敗モード**: エージェントが古い文脈で自信を持って判断する。…
**損害は無駄になった$20 の API クレジットであって、$10k ではない**。…
予算のガードレールは重要だが、**鮮度チェックのほうがもっと重要**。承認ゲートについては…
**実務上、承認の摩擦が自律性の価値を殺す**」
→ これが一般化するなら、**硬い上限への支払意思は恐怖の物語が示すより低く、
承認ラダーは最も求められていない機能ということになる。**

**5. エージェント購買が実際に規模を持つ場所では、プラットフォームが既に政策レイヤーを持っている。**
Clay はワークブック単位のクレジット上限、Mercury は「エージェントは自分の上限を上げられない」
Agent Cards、Skyfire / Payman / Nevermined はいずれもレールと政策を束ねている。
`推論` **独立型・レール非依存のウォレットは、エージェントが買っている当のものに無料で付いてくる
統制に勝たなければならない。**
