## 0. 方法論（先に読む）

### 0.1 母集団は解決済みの問題だった

**TrustMRR**（`trustmrr.com`）が決定的。決済プロバイダ（Stripe / RevenueCat / LemonSqueezy /
Polar / Superwall）の API で検証された収益を公開しており、**自己申告ではない**。
AI カテゴリだけで約 3,569 社。MCP サーバ（`trustmrr.com/mcp`）も公開されている。

**したがってリスト構築は手作業ではなくクエリで行う。** 推奨手順:

1. TrustMRR の AI / Content Creation / Entertainment カテゴリを MCP 経由で取得
2. `$5k ≤ MRR ≤ $100k` かつ `NOT for_sale` でフィルタ
3. 創業者ハンドルだけ人手でエンリッチ（ここが唯一のボトルネック）

歩留まりの実測: AI カテゴリ約30社を精査して、consumer/prosumer AI アプリは8〜10社、
うち収益帯が合うのは約半分、さらにその**約40%が売却中**。
**通過率はおよそ 1/8〜1/10**。3,569社に対して有資格プールは理論上 350〜450社で、
必要な10〜15社に対して十分過ぎる。

### 0.2 発見した精度上のリスク（重要）

**検索エンジンの要約は、無関係な企業間で数字を取り違える。**
実例: `$19.3K verified MRR (1,012 active subscriptions)` という同一文字列が、
ある検索では A 社、別の検索では B 社に帰属して返された。一次ページを直接取得すると
どちらとも異なる数字だった。別の例では、all-time 収益が 30日収益として報告されていた。

**規則: 数字は必ず一次ページの直接取得で確認する。検索結果の要約を引かない。**
`icp-interviews.md` §1-4「数字を必ず1つ持ち帰る」の前段として、
**こちらが持っていく数字も同じ基準で検証されていなければならない。**

### 0.3 経路別の生産性

| 順 | ソース | 評価 |
|---|---|---|
| 1 | **TrustMRR** | 圧倒的。検証済み収益・創業者名・サブスク数・チーム規模・売却中フラグが構造化されている |
| 2 | **Indie Hackers のインタビュー記事** | 質は最高（創業者ハンドル + 収益 + 日付 + 価格モデルが1ページに揃う）だが量が少ない |
| 3 | 汎用 Web 検索 | **低品質かつ有害**。SEO まとめ記事ばかりで、帯外の有名企業を再循環させ、§0.2 の取り違えを起こす。一次ソースの特定にのみ使う |
| 4 | Product Hunt / Acquire.com / Reddit | 今回は不作。売却中在庫は TrustMRR 側がより良いデータで持っている |

### 1.4 Product A リストの所見

1. **10社は余裕で埋まる。** Tier 1 の7社 + Tier 2 の要検証分 + ウォッチリスト昇格で足りる。
   §0.1 の手順を回せば数十社まで拡張可能
2. **売却中フラグの除外が最重要フィルタ。** 有資格に見える企業の約40%がこれ。
   退出中のオーナーは新しい monetization インフラを買わない
3. **創業者名の特定が唯一のボトルネック。** プロフィールの約半分しか創業者を明記していない
4. **Q-05 の検証材料が揃った。** AIWriteBook が RevenueCat、他は Stripe。
   モバイル課金比率の高い層が実在することが確認できたので、
   ヒアリング §2.2-D の質問（Stripe か / モバイルはあるか）は必ず全社に聞く
5. **ブランド適合の事前判断が2社で必要**（Fiddl.art / Lunchbreak）。
   §4.6 に照らして、接触する / しないを**リスト段階で決めておく**。
   面談後に「この事例は使えない」と気づくのは時間の無駄

### 1.5 除外基準（明文化）

以下は ICP に見えても**数えない**。除外した社数は記録する（`icp-interviews.md` §0）。

- 売却中（For Sale フラグ、または創業者が退出を公言）
- 直近30日収益が MRR に対して極端に低い（停止・衰退の兆候）
- AI が機能であってコスト中心ではない（ゲーム、ユーティリティ）
- 10人を大きく超えるチーム、または大型調達済み
- Master Doc §4.6 のブランド NG に抵触する事業内容
