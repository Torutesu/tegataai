## 1. ロゴ

| ファイル | 用途 |
|---|---|
| `brand/tegata-mark.svg` | 主ロゴ。二つの証券にまたがる一つの印影（割印） |
| `brand/tegata-mark-mono.svg` | 単色（墨）。印刷・刻印・低彩度環境 |
| `brand/tegata-seal.svg` | 印影単体。favicon / アバター / 16px 以下 |
| `brand/tegata-lockup.svg` | マーク + ワードマーク横組み |

**構造の意味**: 二つの矩形 = 振出と裏書、Credits と Wallet、要求する側と承認する側。
その両方にまたがる一つのリング = 割印。**片方だけでは成立しない認可**を1マークで言う。
印影をベタ円でなくリングにしているのは意図的（ベタの赤円は日の丸に読める。Master Doc §4.6-2）。

**使用規則**
- クリアスペース: 印影の半径ぶん。最小サイズ: マーク 24px / 印影単体 16px
- 24px 未満では `tegata-seal.svg` に切り替える（罫線が潰れるため）
- 反転時も印影は朱のまま（ダーク地で検証済み）。朱が使えない環境のみ mono
- 禁止: 回転・グラデーション・影・印影の色変更・矩形と印影の分離配置
- ワードマークは Inter 600 / トラッキング 0.19em の仮組み。**公開前にアウトライン化する**

## 2. カラートークン

| トークン | HEX | 用途 |
|---|---|---|
| `--tegata-paper` | `#F7F4EE` | 地。証券用紙の極薄ウォームグレー |
| `--tegata-paper-deep` | `#EFEBE2` | 面の段差・テーブルヘッダ |
| `--tegata-ink` | `#211E1A` | 本文・主ロゴ線。純黒を使わない |
| `--tegata-ink-2` | `#6B6659` | 補助テキスト・注記 |
| `--tegata-rule` | `#CFC9BB` | 罫線・区切り・表罫 |
| `--tegata-shu` | `#B8432F` | 印影。**アクセントはこれ1色のみ** |

- 朱は「押す」場面に限定する: ロゴ、CTA、不渡り/負値の強調、承認アクション。装飾に使わない
- SHOGUN の `#C8A96E` とは意図的に別系統（Master Doc §4.7）
- ダーク地は `--tegata-ink` を地に、紙色を文字に反転。朱はそのまま

**チャートの極性配色**（dataviz 検証済み 2026-08-21）: 負値 `#B8432F` / 正値 `#8A8272`、
サーフェス `#F7F4EE`。CVD 分離 ΔE 8.8（deutan）で合格、コントラスト ≥3:1 合格。
正値側の chroma floor 警告は「無標のニュートラル極」という意図のため適用除外 —
ただし**ゼロ線ラベルと凡例の二次符号化を必須**とする。

## 3. タイポグラフィ

| 役割 | 書体 | 備考 |
|---|---|---|
| EN 見出し・本文 | Inter | 600 / 400。トラッキングは見出しのみ +0.01em |
| 数字・金額・ID・コード | IBM Plex Mono | 通し番号・台帳・レイテンシ表示は必ず等幅 |
| JA | Noto Sans JP | 500 / 400 |

**数字は等幅**が最重要規則。台帳・残高・face_value が桁で揃わない UI はこのブランドではない。

## 4. モチーフの使い方（証券の構造）

| モチーフ | 使い方 | 過剰の例（禁止） |
|---|---|---|
| 罫線 | セクション区切り・表。1px `--tegata-rule` | 二重線・飾り罫 |
| 通し番号 | ドキュメント・レシート・図版に `No. 000123` を振る | 意味のない乱数の羅列 |
| 割印 | 承認・検証済みの意匠。ページ角に小さく | 透かし化・全面パターン |
| ミシン目 | 切り取り境界（before/after、無料/有料の境界表現） | 装飾破線の乱用 |

紙の質感・テクスチャ画像・和柄は使わない（Master Doc §4.7 禁止事項）。構造だけを借りる。
